# SQL Case Study

This project contains a SQL case study based on sales, profit, marketing, inventory, and product analysis using relational databases.

The project demonstrates practical SQL concepts including joins, aggregate functions, stored procedures, window functions, rollup, user-defined functions, and data analysis queries.

---

# Tables Used

## 1. FactTable
Contains transactional and sales-related data.

### Columns
- Date
- ProductID
- Profit
- Sales
- Margin
- COGS
- Total_Expenses
- Marketing
- Inventory
- Budget_Profit
- Budget_COGS
- Budget_Margin
- Budget_Sales
- Area_Code

---

## 2. ProductTable
Contains product information.

### Columns
- Product_Type
- Product
- ProductID
- Type

---

## 3. LocationTable
Contains location and market-related information.

### Columns
- Area_Code
- State
- Market
- Market_Size
